# 广告优化建议规则

建议只描述方向，不提供未经验证的具体竞价、预算金额或调整比例。助手只能解释引擎返回的建议，不能通过此文档自行补充未实现的动作。

## 决策顺序

1. 核对对象与最小可控位置，再核对样本和目标。
2. 优先处理低效子项，避免一个差关键词导致整个活动被处理。
3. 同一搜索词跨位置表现分化时，逐个比较合格的差位置，保留所有表现好的位置。同一广告组内同时有达标与低效来源时，不输出会覆盖该广告组有效流量的否定或隔离建议。
4. 提高预算优先于提高竞价；没有预算约束证据不等于已证明没有约束。
5. 不同动作只在同一具体位置去重；一个位置的隔离建议不得删除其他位置的处理建议。

## 已实现的动作

- `lower-bid`：关键词或投放达到零订单点击门槛，或至少 2 单且 ACoS 超过目标 1.2 倍；自动广告组只有达到门槛的自动子项方向一致、没有更小层级建议时才考虑降低默认竞价。
- `pause`：仅支持推广商品。商品严重低效、同广告组有合格商品表现更好，且该商品自身日趋势通过两个独立区间的持续性门槛。缺历史时保留观察，不输出暂停。
- `harvest-search-term`：至少 3 单、ACoS 达标，类型已知且返回的正向投放位置列表明确为空；文字提取为精准关键词，ASIN 提取为精准商品投放。已有投放时不重复建议创建。
- `negative-search-term`：零订单且达到否定点击门槛；类型已知，来源活动/广告组的否定列表完整且未包含它。只建议在来源最小安全范围精准否定。
- `isolate-search-term`：同一规范搜索词存在达标位置与低效位置，且差位置的否定状态可确认；每个差位置独立比较与输出。保留有效位置，不在仍含有效流量的活动层面全局否定。
- `increase-bid`：已有关键词/投放本身及关联搜索词均至少 3 单且达标；展示份额低于 100%、排名大于 1，并且已取得活动日预算证据且没有受限日。
- `increase-budget`：活动至少 3 单且 ACoS 达标，日历史有至少两个实际预算受限日。使用接口明确的超预算时点、超预算分钟数或逐日历史预算；当前预算、今日消耗比例和建议预算不能独立触发。
- `reduce-budget`：活动严重低效且通过持续性门槛，相关子实体完整、指标可用、没有明确赢家，也没有更小范围的安全动作时，建议降低预算并排查结构。
- `lower-placement-bid`：SP 活动广告位至少 2 单且明显低效，同时另一个广告位达到目标。只有现有加价可降低时才输出方向；不以广告位份额单独判断。
- `review-structure`：至少 3 个启用活动本期零花费，且占启用活动一半以上时，建议检查结构；不等同于建议暂停。

## 数据与去重

搜索词按去除首尾空格、统一大小写、折叠连续空格归组；ASIN 使用大写。不得用来源关键词名称替代实际搜索词。保留活动与广告组位置、来源关键词/投放标识和匹配方式。

正向/否定位置缺失时保留数据缺口，不假定“尚未投放/否定”。暂停或降低预算所需的实体历史不能用活动汇总替代。库存、促销、购物车和详情页未经查询，只能写成待核实风险。

## 当前不支持

不生成预算重分配、提高广告位加价、活动/广告组/关键词/投放暂停、否定词组或具体金额比例建议。当前只对搜索词做跨位置隔离，不能宣称已实现所有 ASIN、关键词、投放对象的跨位置优化。这些能力需要额外证据与测试后单独扩展。
